# CheatCode

A local-first learning workspace for algorithm intuition and Python technical interviews.

## Run locally

Requires Node.js 20.19+ or 22.12+ and npm.

```sh
git clone https://github.com/RohitPenna/CheatCode.git
cd CheatCode
npm install
npm run dev
```

Open the local URL printed by Vite. `npm run build` creates a static production build in `dist`. `npm run preview` serves that build. No API keys, database, or paid service are required.

Built with React, TypeScript, Vite, Lucide icons, and CSS. Source and features are being added in functional milestones.
